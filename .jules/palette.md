## 2024-05-24 - Aggregated Screen Reader Focus
**Learning:** For dynamic UI components like lists or cards built dynamically in code (as in Gnix), having many small, interactive child elements can cause screen readers like TalkBack to read the card fragment by fragment, requiring excessive swiping and breaking the logical flow. Individual child views with small touch targets also provide a disjointed UX.
**Action:** Always apply click listeners (`ui.clickable`) and aggregated `contentDescription`s on the highest level parent container representing a logical item (e.g. the article card). Set `View.IMPORTANT_FOR_ACCESSIBILITY_NO` (or `NO_HIDE_DESCENDANTS` where appropriate) on the individual child views inside it. This provides a unified, optimally sized touch target and cohesive screen reader focus block.
