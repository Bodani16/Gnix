## 2024-05-24 - TalkBack grouping of non-interactive elements
**Learning:** When grouping dynamic UI elements for TalkBack, do not apply aggregated `contentDescription`s or focus directly to a parent container if it has interactive child elements. Doing so swallows child focus. Furthermore, do NOT set `View.IMPORTANT_FOR_ACCESSIBILITY_NO` on the child text elements (like metadata, headline, summary) as it completely removes them from the accessibility tree, causing the screen reader to announce a blank, clickable element instead of aggregating their text.
**Action:** Encapsulate the non-interactive text elements into a dedicated wrapper (e.g., `ui.column().apply { isFocusable = true }`), remove any individual click listeners or focusable flags from the child elements, and allow Android's default behavior to aggregate the non-focusable child text within the focusable wrapper. Keep interactive elements as separate, accessible siblings.
